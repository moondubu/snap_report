SUMMARY

스냅리뷰 · 스냅푸시 기능 및 전수조사 리포트

스냅리뷰는 리뷰 보상·노출·통계 기능을 제공하며, 스냅푸시는 페이지별 스크립트를 통해 타겟 수집·메시지 발송·온사이트 노출을 처리합니다. 이번 반응형 스킨 이전에 따른 전수조사에서 스냅리뷰는 화면별 리뷰 템플릿의 디바이스별 정상 노출 여부를, 스냅푸시는 주요 페이지의 스크립트 누락 여부를 확인합니다.

스냅리뷰

리뷰 유형별 적립금 차등 설정, 리뷰 노출 템플릿 관리, 리뷰 운영 지표(작성률·평점·답변율) 확인. 검수 대상은 디바이스별 리뷰 템플릿 노출.

스냅푸시

행동 기반 타겟 수집, 카카오톡/문자 캠페인 발송, 온사이트 팝업·배너 노출, 캠페인 성과 리포트. 검수 대상은 페이지별 스크립트 삽입 여부.

1. 스냅리뷰

기능

적립금 템플릿 통계
  • 텍스트 / 포토 / 영상 리뷰별 적립금 차등 설정
  • 글자 수 구간별(예: 50자 이상 / 10~50자 / 10자 미만) 적립금 조건
  • 상품 가격, 구매 금액, 작성 순서(선착순 등) 기준 지급 조건
  • 기본 리뷰 / 한달 사용 리뷰(추가 리뷰) 적립금 별도 설정
  • 리뷰 작성률, 불만족 리뷰 비율, 답변율, 평균 평점 등 운영 지표
  • 시장 평균 대비 상태 비교 (대시보드)
  • 리뷰 노출 위젯 및 템플릿 설정
검수 범위: 사용 중인 각 화면(상품상세, 리뷰 리스트, 포토·영상 리뷰 영역)의 리뷰 템플릿이 PC/모바일에서 정상 노출되는지 확인(완료). 스킨 변경 후 디바이스별 템플릿 정상 노출 모니터링

2. 스냅푸시

기능

캠페인 온사이트 타겟팅 리포트
  • 카카오 알림톡, 친구톡, SMS/LMS 캠페인 발송
  • 이탈 고객, 장바구니 미결제 고객 등 조건별 자동 발송
  • 쿠폰 팝업, 회원가입 유도 배너 등 온사이트 디자인 노출
  • SCRM 기반 고객 세그먼트 생성 및 타겟 관리
  • 카페24 회원/주문 데이터 동기화 (스냅 싱크)
  • 카카오모먼트 광고 연동
  • 캠페인별 매출 전환, 상품 유입, 사용자 이탈 등 성과 리포트
기능 구분 동작 스크립트 누락 시 영향
캠페인 발송 카카오톡/문자 메시지 자동 발송 발송 트리거 조건 미충족
온사이트 디자인 팝업, 배너 노출 팝업/배너 미노출
타겟 수집 SCRM 행동 데이터 수집 타겟 세그먼트 생성 불가
검수 범위: 메인, 상품목록, 장바구니 등 주요 페이지에 스냅푸시 스크립트가 누락 없이 삽입되어 있는지 확인.

6. 번외 - 카페24 레시피

개요

카페24 레시피는 쇼핑몰 이벤트(트리거)와 동작(액션)을 연결하는 업무 자동화 플랫폼입니다. "리뷰 작성하면 적립금 지급", "주문 접수되면 라인으로 알림" 같은 if-then 패턴으로 약 900여 개의 자동화 패턴을 제공합니다. 카페24 내장 서비스로 무료로 사용 가능합니다.

주요 기능

  • 트리거 — 주문 접수, 리뷰 작성, 회원 가입, 문의 등록, 반품 접수, 스케줄(특정 요일/시간) 등
  • 액션 — 라인·텔레그램 알림 발송, 구글시트 데이터 업로드, 상품 정보(해시태그·진열 여부) 자동 수정, 적립금 지급
  • 트리거 + 액션을 조합해 나만의 자동화 패턴 생성 가능
  • 코드 없이 클릭 몇 번으로 설정 완료
기능 영역 레시피로 가능한 범위 레시피로 불가능한 범위
리뷰 적립금 리뷰 작성 시 일괄 적립금 지급 자동화 리뷰 유형·글자 수·상품 가격별 차등 지급 조건 없음
메시지 발송 라인, 텔레그램으로 내부 알림 (운영자용) 카카오톡 알림톡·친구톡, SMS/LMS 고객 대상 발송 불가
타겟팅 특정 이벤트 발생 시 단순 조건 분기 행동 기반 고객 세그먼트(SCRM), 이탈 타겟팅 불가
온사이트 노출 해당 없음 팝업·배너 노출, 조건별 온사이트 디자인 불가
성과 분석 구글시트로 데이터 내보내기 캠페인 전환 추적, 이탈 분석, 통합 리포트 없음
판단: 카페24 레시피는 운영자 내부 알림·단순 반복업무 자동화 도구입니다. 고객 대상 카카오톡 발송, 행동 기반 타겟팅, 온사이트 팝업, 성과 리포트는 지원하지 않으므로 스냅푸시를 대체하기 어렵습니다. 스냅리뷰의 리뷰 적립금 지급은 레시피로 일부 자동화할 수 있지만, 차등 조건 로직과 운영 지표 대시보드는 카페24 기본 기능 + 레시피 조합으로 구현이 불가능합니다.
